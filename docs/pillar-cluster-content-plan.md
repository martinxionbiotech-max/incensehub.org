# IncenseHub — Pillar + Cluster Content Plan

> 版本：2026-11-04
> 目标：用 5 个 Pillar 组织全站内容，每个 Pillar 带 10–20 个 Cluster；每周一次夜间更新，持续 5 周一个循环。
> 定位：内容层 + 数据库层；不做商业落地页，不做 LanDeng 内容。

## 1. 五个 Pillar

| # | Pillar | URL | 角色 |
|---|---|---|---|
| 1 | Chinese Incense History & Culture | `/chinese-incense/`（现有） | 历史、香道、古籍、文化 |
| 2 | Agarwood & Sandalwood Knowledge | `/agarwood-sandalwood/`（新建） | 沉香/檀香、等级、形成机制 |
| 3 | Incense Materials & Authentication | `/incense-materials/`（新建） | 150+ 香材、鉴别、替代 |
| 4 | Traditional Incense Craft & He Xiang | `/hexiang-craft/`（新建） | 香方、配伍、生产工艺 |
| 5 | Incense Science & Safety | `/incense-science-safety/`（新建） | 化学、燃烧、空气质量 |

Pillar 页标准：4,000–6,000 词、12–18 个 H2、1 个 “Start here” 导航、1 个决策框架、8–12 条 FAQ、15–20 个 cluster 链接、5+ 来源。

## 3. Cluster 标准

每篇 cluster：
- 2,000–3,500 词
- 8–12 个 H2；开头 Direct answer 40–60 词
- 至少 8 个“只有这页才有”的数据点/判断
- 1 个 “Our read”（明确推荐/不推荐）
- 5+ 来源；1 个 `last reviewed`
- 10+ 内链：Pillar、2 个同级、3 个相关、2 个数据实体
- 句间重叠 <5%；不复制数据站全文

### 3.1 写作标准（强制，deep-research-human-writer v3）

每篇 Pillar / Cluster 必须按以下流程：

> Intent → Entity → Research → Evidence → Verification → Normalization → Analysis → Contradiction Resolution → Information Gain → Content Architecture → Human Writing → SEO/GEO/AIO → E-E-A-T → QA

**禁止 Search → Rewrite → Publish。**

1. **碎片 → 观点**
   - 8–12 个中文/英文来源；每条 claim 标 `F / D / I / E / U`
   - 建 contradiction log：来源冲突、为什么冲突、对读者意味着什么
   - 先形成“我的判断”，再找证据支撑；不是先抄再改

2. **原创性**
   - 句间重叠 <5%；不得整段改写
   - 每页 8+ 个“只有这页才有”的数据点/框架/决策规则
   - 必须回答：读者看完前 5 个搜索结果，这页还多给什么？

3. **作者立场**
   - 固定板块 `## The Author's Take`
   - **Position**：一句可引用、第一人称、明确支持/反对
   - **Reasoning**：2–3 条具体理由
   - **Disclosure**：明确这是编辑判断，不是事实
   - 观点可以锋利，但不能夹带医疗/法律/安全断言

4. **人味**
   - 避免 `In today's...`、`It is important to note...`、`This comprehensive guide...`
   - 具体观察、条件推理、技术细节、真实限制；长短句混合
   - 允许不确定性与反常识判断

5. **硬禁区**
   - 不编来源、数字、亲身经历、认证、测评
   - 不保留未解决的重大矛盾
   - 不做重复 intent 页
   - 不写模板化“10 个要点”凑字数

6. **QA**
   - 120 分制；cornerstone ≥95
   - Gate：Evidence / Accuracy / Originality / Intent / Entity / SEO / GEO-AIO / E-E-A-T

## 4. 内链规则

- Pillar → 所有 cluster（按主题分组）
- Cluster → Pillar（首段或文末）
- Cluster ↔ 相关 cluster（2–3 条）
- 原料页 ↔ `/incense-materials/` + 数据实体
- 数据实体 `mainEntityOfPage` → 主站内容页
- 每个 Pillar 至少 15 个出站 cluster 链接；每个 cluster 至少 1 个回链

| 周 | Pillar | 本周产出 |
|---|---|---|
| W1 | History & Culture | Pillar 刷新 + 2 个新 cluster |
| W2 | Agarwood & Sandalwood | Pillar 新建/刷新 + 2 个新 cluster |
| W3 | Materials & Authentication | Pillar 新建/刷新 + 2 个新 cluster |
| W4 | Craft & He Xiang | Pillar 新建/刷新 + 2 个新 cluster |
| W5 | Science & Safety | Pillar 新建/刷新 + 2 个新 cluster |
| W6 | 回到 W1 | 刷新 + 补缺口 |

每周固定动作：
1. 刷新本周 Pillar（补新 cluster 链接、更新数据/日期）
2. 写 2 篇 cluster（1 篇新缺口 + 1 篇旧页加深）
3. 内链：Pillar ↔ cluster ↔ 相关页
4. `npm run build` + 相似度验证（<0.40）
5. commit + push
6. 周报：本周页、字数、链接、构建、下周队列
